# coral-catalog

Public model catalog used by the Coral macOS app (`models.json`).

This repository is **generated**: it is synced automatically from Coral's main repository
whenever `models.json` changes there. Don't edit it by hand; changes here are overwritten.

The app reads `https://raw.githubusercontent.com/marcosnovo/coral-catalog/main/models.json`.
Every benchmark lists its public source, date, and whether it is independent or vendor-reported.
